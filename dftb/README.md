# DFTB+

Examples using [DFTB+](https://dftbplus.org) as the force calculator
for kALDo thermal conductivity calculations.

DFTB (Density Functional Tight Binding) is a semi-empirical quantum
mechanical method that offers a good balance between accuracy and
computational cost for large systems.
